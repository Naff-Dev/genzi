# naffdev-product-engineer

Plugin and Skill package for Antigravity and Gemini coding agents.

## Activation Trigger

Activate the `naffdev-product-engineer` skill whenever the user asks to build, design, architect, or add a feature to any web app, mobile app, dashboard, or software product.

## Key Directives

- Read `skills/naffdev-product-engineer/SKILL.md` before coding.
- Read reference guides in `skills/naffdev-product-engineer/references/` when executing specific phases (workspace detection, PRD generation, design guidelines, and review checklist).
- Never skip desktop and mobile responsive verification.
- Avoid generic AI slop in UI, copy, and code architecture.
- Do not use em-dash characters.
